# Zikr Companion — Checklist de publication

## Qualité produit

- [ ] Premier lancement : l'intention apparaît et le bouton Commencer fonctionne.
- [ ] Compteur tactile : incrément, haptique, progression et complétion.
- [ ] Mode chapelet : geste vertical, boutons Ajouter/Retirer et action VoiceOver réglable.
- [ ] Passage de minuit : compteur remis à zéro sans relancer l'application.
- [ ] Matin puis soir le même jour : deux entrées d'historique, une seule progression de série.
- [ ] Historique restauré après fermeture complète de l'application.
- [ ] Rappel local créé, modifié et annulé sur appareil physique.

## Accessibilité

- [ ] VoiceOver : parcours logique, libellés compréhensibles, aucun contrôle uniquement visuel.
- [ ] Taille de texte Accessibilité : contenu lisible sans action inaccessible.
- [ ] Réduire les animations : aucune transition de grande amplitude.
- [ ] Contraste vérifié pour l'or, le texte secondaire et les états désactivés.

## Contenu et confidentialité

- [ ] Arabe, translittération et traduction relus et sources documentées.
- [ ] `PrivacyInfo.xcprivacy` présent dans l'archive.
- [ ] Déclaration App Privacy cohérente : aucune donnée collectée par Dakhine.
- [ ] URL de politique de confidentialité et URL de support publiées.

## Distribution

- [ ] Certificat Apple Distribution et profils valides installés.
- [ ] Numéro de build incrémenté.
- [ ] Build Release et archive sans avertissement bloquant.
- [ ] Icônes normale, sombre et teintée vérifiées sur appareil.
- [ ] Captures App Store réalisées sur les formats demandés.
- [ ] Beta TestFlight effectuée avant soumission App Store.
